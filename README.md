# 🧭 AI-Powered Trip Planner

An intelligent trip planner built using **CrewAI**, **Ollama LLMs**, and **Flask**, that helps users generate personalized, optimized travel itineraries and local guidance with just one input: their travel destination!

## ✨ Features

- 🔍 Smart travel planning with agent collaboration
- 🧑‍🏫 Local insights, cultural advice & food tips
- 🧠 Powered by Ollama's LLMs with CrewAI orchestration
- 🌐 Minimal, fast Flask web interface
- 📦 Modular file structure (agents, tasks, tools, routes)

## 🧪 Tech Stack

- **Python**
- **Flask** (Web app)
- **CrewAI** (Multi-agent orchestration)
- **Langchain-Ollama** (LLMs)
- **HTML/CSS** (Frontend)
